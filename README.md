# lbfood-site

Site institucional da LB Food (lbfood.com.br).

- `index.html`: página da LB Food
- `pipok/index.html`: página da marca Pipok
- `assets/`: estilos (`css/`) e imagens (`img/`)

Site estático, sem etapa de build: qualquer hospedagem estática (GitHub Pages, Netlify, Vercel) publica a pasta raiz como está.
